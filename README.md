# Rupom Digital — Premium Business Website

**Owner / author:** Mahmudul Haq Rupom

A modern responsive digital-studio website built with HTML5, CSS3 and vanilla JavaScript.

## Updated visual direction
- Real editorial workplace photography from Unsplash instead of AI-style abstract illustrations
- Warm honey / amber / golden-yellow colour grading
- Rich photo overlays, natural contrast and hover zoom
- Interactive cursor spotlight and scroll progress bar
- 3D pointer tilt on the hero visual and cards
- Hover glow, card lift, icon movement and staggered reveal animations
- Responsive mobile navigation and day/night theme toggle

## Folder structure
- `index.html`
- `CSS/style.css`
- `JavaScript/main.js`
- `Images/README.txt` — image source and attribution notes

## Run
Extract the ZIP, open the folder in VS Code and run `index.html` with Live Server.
Internet is required for Unsplash photos, Google Fonts and Font Awesome.
